# make a table of the cooking times for the different kinds of rice and pasta

Here is a concise, generic table of stovetop cooking times for common rice types and dried pasta shapes (simmer/boil time only, not including soaking or resting).

## Rice cooking times (simmering)

| Rice type | Typical simmer time (minutes) |
| :-- | :-- |
| Long‑grain white | 15–18 [^1_1] |
| Jasmine | 12–15 [^1_1] |
| Basmati (white) | 15–18 [^1_1][^1_2] |
| Short/medium‑grain white | 15–20 [^1_3][^1_4] |
| Sushi rice (short‑grain) | 18–20 [^1_1] |
| Brown long‑grain | 35–40 [^1_1][^1_5] |
| Brown basmati | 12–14 (boil‑and‑drain) [^1_5] |
| Wild rice / blends | 45–55 [^1_1] |
| Parboiled (converted) | ~20 [^1_3][^1_4] |
| Instant/quick rice | 5–10 (per package) [^1_6] |

## Pasta cooking times (boiling)

These are approximate “al dente” times for typical dried wheat pasta; always taste and adjust.


| Pasta type (dried) | Typical boiling time (minutes) |
| :-- | :-- |
| Angel hair / Capellini | 4–6 [^1_7][^1_8] |
| Spaghetti | 8–10 [^1_9][^1_7][^1_8] |
| Linguine | 8–10 [^1_9][^1_7] |
| Bucatini | 10–12 [^1_7] |
| Penne | 9–13 [^1_9][^1_8][^1_7] |
| Ziti | 6–8 (some brands 12–15) [^1_9][^1_7] |
| Rigatoni | 11–13 [^1_7][^1_9] |
| Farfalle (bow ties) | 10–12 [^1_8][^1_7] |
| Fusilli / Rotini | 8–10 [^1_7][^1_8] |
| Macaroni (elbows) | 8–10 [^1_8][^1_9] |
| Shells (conchiglie) | 8–15, size‑dependent [^1_8][^1_7] |
| Pappardelle | 7–10 [^1_8][^1_10] |
| Fettuccine | 6–8 (nests 13–14) [^1_7][^1_10] |
| Lasagna noodles | 12–15 [^1_9] |
| Egg noodles (regular) | 8–10 [^1_9] |
| Fresh / refrigerated pasta | 1–5, shape‑dependent [^1_9][^1_10] |

These ranges are good starting points; for any specific brand or shape, checking the package and tasting a minute or two early usually gives the best result.
